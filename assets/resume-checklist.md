# 이력서 점검 체크리스트

지원 버튼을 누르기 전에 순서대로 확인합니다.

## 근거

- [ ] 모든 성과 문장에 숫자나 결과물이 있다
- [ ] "참여", "담당" 같은 모호한 동사가 없다
- [ ] 없는 경험을 쓰지 않았다
- [ ] 기술 스택에 실제로 써본 것만 있다

## 공고 정합성

- [ ] 공고의 핵심 요구사항이 이력서 상단 절반에 보인다
- [ ] 공고에서 쓰는 용어와 같은 용어를 썼다
- [ ] 이 공고와 무관한 경험을 과감히 뺐다

## 형식

- [ ] 한 페이지(경력 5년 미만) 또는 두 페이지 이내
- [ ] PDF로 제출 가능한 파일명이다
- [ ] 연락처와 링크(GitHub, 포트폴리오)가 열린다
