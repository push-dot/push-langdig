링크와 파일이면 충분합니다.

복사·붙여넣기를 반복할 필요가 없습니다. Push가 직접 읽고, 근거를 붙이고, 결과물을 만듭니다.

공고 링크를 직접 읽음

원티드·잡코리아 링크를 던지면 페이지를 직접 가져와 분석합니다. 자격요건과 우대사항을 뽑아 이력서와 1:1로 대조합니다.

PDF를 증거로 사용

이력서 PDF를 드래그해서 놓으면 텍스트를 추출해 증거 자료로 저장합니다. 생성되는 모든 문장은 그 증거에 근거합니다. 없는 경험은 쓰지 않습니다.

단계별 이력서 워크플로

분석 → 전략 → 초안 → 검수까지 단계마다 확인을 거칩니다. 마음에 들 때까지 다듬고, 산출물은 파일로 남습니다.

던지고, 확인하고, 끝내기.

01

공고 링크

채용공고 URL을 채팅에 붙여넣습니다. Push가 페이지를 읽습니다.

02

이력서 드롭

PDF를 끌어놓으면 자동으로 추출·첨부됩니다.

03

단계별 생성

JD 분석부터 초안, 검수까지 게이트를 두고 진행합니다.

04

산출물 저장

완성된 자기소개서·이력서는 파일로 내보냅니다.

내 데이터는 내 통제 아래.

이력서는 민감한 정보입니다. Push는 필요한 것만, 허락된 것만 사용합니다.

승인 게이트

증거 사용, 문서 확정, 외부 액션은 각각 사용자 승인을 요청합니다. AI가 임의로 진행하지 않습니다.

BYOK 지원

관리형 모델 외에 내 API 키로 OpenAI·Claude·Grok·OpenRouter를 직접 연결할 수 있습니다. 키는 암호화되어 저장됩니다.

근거 없는 주장 금지

자기소개서의 모든 문장은 첨부한 이력서, 공고, 직접 말한 내용에서만 나옵니다. 출처를 남겨 나중에 검증할 수 있습니다.
