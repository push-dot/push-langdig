Push는 당신의 이력서와 GitHub에서 근거를 모아, 채용 공고에 맞는 이력서와 자기소개서를 단계별로 만들어줍니다.

앱 받기 어떻게 작동하나요

근거 수집

이력서·GitHub·공고 URL

올린 자료와 리포에서 경력 근거를 청크로 나눠 모읍니다.

단계별 게이트

Fit score → 전략 → 초안

각 단계마다 결과를 보여주고 진행할지 묻습니다.

완성 문서

이력서·자소서·PDF

생성물이 문서로 저장되고 PDF·DOCX로 내려받습니다.

AI가 지어낸 문장이 아니라, 당신의 근거에서 나온 문장

Push는 없는 경험을 만들지 않습니다. 올린 이력서와 리포에서 찾은 근거만으로 씁니다.

단계마다 사람이 승인합니다

공고 분석, Fit score, 작성 전략, 초안, 품질 검증. 각 Phase에서 멈춰 결과를 보여주고, 넘길지 고칠지 당신이 정합니다.

Fit score 게이트

공고 적합도: 높은 편

핵심 요구 6개 중 5개에 근거가 있습니다. 부족한 1개: 대규모 트래픽 경험.

진행 수정 요청

근거 검색, RAG

경력 청크를 벡터로 검색해 프롬프트에 주입합니다. 근거 없는 주장은 생성되지 않습니다.

끊기지 않는 작업

페이지를 나갔다 와도 진행 중이던 생성이 이어집니다. 스트림이 자동으로 재연결됩니다.

이력서에서 끝나지 않습니다

같은 근거로 포트폴리오, 자기소개서, 면접 준비, 프로젝트 기획서까지 만듭니다. 공고마다 지원 항목이 자동으로 정리됩니다.

이력서 자기소개서 포트폴리오 면접 준비 지원 관리

공고 하나면 시작됩니다

  1. 올리기

    근거를 올리기

    이력서 파일을 올리고 GitHub을 연결합니다. 채용 공고 URL을 붙여넣으면 지원 항목이 자동으로 생깁니다.

  2. 검토하기

    단계별로 검토하기

    Fit score와 작성 전략을 확인하고 승인합니다. 마음에 안 들면 그 자리에서 수정을 요청합니다.

  3. 받기

    문서로 받기

    완성된 이력서는 문서로 저장됩니다. 에디터에서 다듬고 PDF·DOCX로 내려받아 바로 지원합니다.

당신의 경력은 당신의 것입니다

올린 근거는 당신의 문서를 만드는 데만 쓰입니다. 생성된 문장이 어느 근거에서 왔는지 확인할 수 있습니다.

  • 근거 기반 생성

    모든 문장이 올린 자료에서 나옵니다.

  • 승인 없이 진행 없음

    각 단계는 당신이 넘길 때까지 멈춥니다.

  • 모델 선택권

    관리형 모델 또는 내 API 키(BYOK)로 실행합니다.

  • 언제든 삭제

    근거와 문서는 언제든 지울 수 있습니다.

다음 지원부터 달라집니다
