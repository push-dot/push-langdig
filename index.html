밀어넣는 영어,
파고드는 학습

push-langdig는 하루 몇 번의 짧은 푸시로 단어와 표현을 밀어넣고, 문맥 속 예문으로 깊게 파고들게 만드는 영어 학습 도구입니다. 앱을 열지 않아도, 알림이 공부를 시작합니다.

저녁 복습

맞힌 표현 2개

내일 다시 물어볼 표현 1개

간격 반복이 내일 아침 카드를 정합니다.

Features

앱을 여는 수고를
없앴습니다

영어 학습이 무너지는 이유는 의지가 아니라 마찰입니다. push-langdig는 학습을 알림 안으로 옮겨 마찰을 지웠습니다.

푸시 기반 학습

정해진 시간에 카드가 알림으로 도착합니다. 탭 한 번으로 뜻을 확인하고, 알겠다와 모르겠다만 고르면 학습이 끝납니다.

문맥 속 파고들기

단어만 외우지 않습니다. 실제 문장과 상황 속에서 표현을 파고들어 언제 어떻게 쓰는지까지 익힙니다.

간격 반복 엔진

맞힌 카드는 간격을 벌리고, 틀린 카드는 간격을 좁힙니다. 잊기 직전에 다시 밀어넣어 기억을 오래 붙듭니다.

Learning Flow

하루 세 번,
각 30초

  1. 01

    푸시가 도착합니다

    아침 출근길, 점심 직후, 잠들기 전. 직접 정한 시간에 오늘의 카드가 알림으로 옵니다. 앱 아이콘을 찾을 필요가 없습니다.

  2. 02

    예문으로 파고듭니다

    표현을 눌러 실제 문장, 발음, 비슷한 표현까지 확인합니다. 30초면 한 표현의 쓰임을 통째로 가져갑니다.

  3. 03

    간격이 다시 밀어넣습니다

    오늘 반응한 결과가 내일의 카드 순서를 정합니다. 잊을 만할 때 다시 도착하니까, 따로 복습 계획을 세울 필요가 없습니다.

Privacy

학습 데이터는
기기 안에 둡니다

push-langdig는 계정도, 서버 동기화도 없습니다. 무엇을 알고 무엇을 모르는지는 오직 내 기기만이 압니다.

  • 로컬 우선 저장

    진행 상황과 카드 기록은 전부 기기 안 저장소에 남습니다.

  • 추적 없음

    광고 ID, 사용 분석, 제3자 추적 코드를 포함하지 않습니다.

  • 계정 불필요

    이메일도 비밀번호도 요구하지 않습니다. 설치 즉시 시작합니다.
